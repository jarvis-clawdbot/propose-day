# 💕 Propose Day Website

A beautiful, romantic, and interactive Propose Day website created with love. This website features multiple pages, animations, and interactive elements to make your special day memorable.

![Propose Day](https://img.shields.io/badge/Propose-Day-c41e3a?style=for-the-badge&logo=heart)

## ✨ Features

- **🌟 Landing Page** - Beautiful hero section with floating hearts, countdown timer, and interactive messages
- **💌 Love Letter** - An elegant, beautifully styled letter page
- **📝 Quotes Page** - Collection of romantic quotes with category filters
- **📸 Memories Page** - Timeline of your special moments
- **🎨 Animations** - Smooth CSS animations and particle effects
- **💫 Interactive Elements** - Hover effects, click interactions, and more
- **📱 Responsive Design** - Works perfectly on all devices

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/jarvis-clawdbot/propose-day.git
```

2. Open the project folder:
```bash
cd propose-day
```

3. Open `index.html` in your browser

## 🔧 Customization

### Changing Content

Edit the HTML files to customize:
- Letter content in `letter.html`
- Quotes in `quotes.html`
- Timeline events in `memories.html`

### Changing Colors

Edit `styles.css` and update the CSS variables in the `:root` section.

### Adding Photos

Replace the gallery placeholder icons in `memories.html` with actual photos.
